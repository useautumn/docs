title: "useAnalytics"
description: "Query usage analytics data from your React components"

The `useAnalytics` hook provides access to usage analytics and reporting data. It's the client-side equivalent of the [/query](/api-reference/core/query) endpoint, allowing you to fetch and display usage data directly in your React components.

<Note>
  To use Autumn's React hooks, you should set up the `autumnHandler` in your
  backend and the `<AutumnProvider />` in your frontend, as described in the
  [quickstart guide](/setup#4-mount-the-autumn-handler). This gives the hooks
  access to the customerId making the request.
</Note>

## Parameters

<ParamField body="featureId" type="string | string[]" required>
  The feature ID or array of feature IDs to query usage data for.
</ParamField>

<ParamField body="range" type="string">
  Time range for the analytics query. Available options: "24h", "7d", "30d", "90d", "last_cycle". Defaults to "30d" if not provided.
</ParamField>

## Return Values

### `data`

Array of usage data points for each time period. Each item includes:
- `period`: Unix timestamp in milliseconds representing the start of the time period
- Dynamic properties for each queried `featureId` with their usage amounts

### `isLoading`

Boolean indicating whether the analytics data is currently being fetched.

### `error`

Any error that occurred while fetching analytics data.

### `refetch`

Function to manually refetch the analytics data.

{/* ## Examples

### Single Feature Analytics

Query analytics for a single feature:

```jsx
import { useAnalytics } from "autumn-js/react";

export default function MessageUsageChart() {
  const { data, isLoading, error } = useAnalytics({
    featureId: "messages",
    range: "30d"
  });

  if (isLoading) {
    return <div>Loading analytics...</div>;
  }

  if (error) {
    return <div>Error loading analytics: {error.message}</div>;
  }

  return (
    <div>
      <h3>Message Usage (Last 30 Days)</h3>
      {data?.map((point) => (
        <div key={point.period}>
          {new Date(point.period).toLocaleDateString()}: {point.messages} messages
        </div>
      ))}
    </div>
  );
}
```

### Multiple Features Analytics

Query analytics for multiple features simultaneously:

```jsx

export default function MultiFeatureChart() {
  const { data, isLoading, error, refetch } = useAnalytics({
    featureId: ["credits", "messages"],
    range: "7d"
  });

  if (isLoading) {
    return <div>Loading analytics...</div>;
  }

  if (error) {
    return <div>Error: {error.message}</div>;
  }

  return (
    <div>
      <div className="flex justify-between items-center mb-4">
        <h3>Usage Analytics (Last 7 Days)</h3>
        <button onClick={refetch}>Refresh</button>
      </div>
      
      {data?.map((point) => (
        <div key={point.period} className="border p-2 mb-2">
          <div className="font-semibold">
            {new Date(point.period).toLocaleDateString()}
          </div>
          <div>Credits: {point.credits || 0}</div>
          <div>Messages: {point.messages || 0}</div>
        </div>
      ))}
    </div>
  );
```
