---
title: "Set Feature Balance"
openapi: "features POST /customers/{customer_id}/balances"
---

<CodeGroup>

```javascript Node.js
await autumn.customers.updateBalances(customerId, {
  feature_id: "messages",
  balance: 100
});

// Or update multiple balances at once
await autumn.customers.updateBalances(customerId, [
  {
    feature_id: "messages", 
    balance: 100
  },
  {
    feature_id: "api_calls",
    balance: 500
  }
]);
```

</CodeGroup>
